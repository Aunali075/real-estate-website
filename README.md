GLOVANCE REAL ESTATE WEBSITE TEMPLATE
=====================================

Thank you for purchasing this template from
GLOVANCE Digital Solutions.

1. REQUIREMENTS
---------------
- A modern web browser.
- A code editor such as Visual Studio Code.
- An internet connection for the external libraries,
  fonts, images and map services used by this demo.

2. HOW TO OPEN
--------------
1. Extract the downloaded ZIP file.
2. Open the extracted folder.
3. Open index.html in your browser to preview it.
4. Open index.html in your code editor to customize it.

3. HOW TO CUSTOMIZE
-------------------
- Replace the business name and logo.
- Replace sample property names, prices and descriptions.
- Replace sample agent names and contact information.
- Replace the demonstration address and business hours.
- Replace sample property images with your own licensed images.
- Update phone numbers, email addresses and social media links.
- Update the map coordinates for your property locations.

4. PROPERTY DATA
----------------
Property listings and agent details are stored in the
JavaScript section inside index.html.

Search for:
const properties = [

Edit the sample property information there.

5. CONTACT AND NEWSLETTER FORMS
-------------------------------
The forms are configured for Netlify Forms.
Deploy the website to Netlify and enable form detection.
Test each form after deployment.

6. IMPORTANT NOTES
------------------
This is a static HTML template.
It does not include a database, property management
dashboard, user login system or backend CMS.

The included listings, agents and contact details are
demonstration content. Replace them before publishing.

External libraries, fonts, images and map services require
an internet connection.

Agent profiles and testimonials and contents are examples.
And replaceable.
